# Учебный тренажёр ДДС-112

Рабочий прототип локального тренажёра для подготовки диспетчеров ДДС. Система получает готовую учебную карточку 112, направляет её обучающемуся назначенной службы и оценивает обработку по утверждённому преподавателем эталону.

Проект не принимает реальные экстренные вызовы, не подключается к действующей системе-112 и не является промышленным диспетчерским центром. Голос участника происшествия и телефонный разговор в текущий учебный поток не входят.

## Что работает

- три роли: администратор, преподаватель и обучающийся;
- создание пользователей, назначение ролей и блокировка учётных записей;
- создание учебных групп и ограничение доступа к занятиям по составу группы;
- импорт версий классификатора ЕКП из XLSX;
- поиск происшествий, проверка условий и выбор служб-получателей;
- подготовка, утверждение и публикация сценария карточки 112;
- создание, запуск, обычное и досрочное завершение занятия;
- адресный реестр происшествий обучающегося по профилю ДДС;
- таймер, статусы, комментарии, сведения ДДС и журнал действий;
- детерминированная оценка порядка действий и временных нормативов;
- архив, подробный отчёт, экспорт CSV и PDF;
- сводная динамика результатов обучающихся;
- серверный RBAC, аудит значимых действий и экран состояния локального комплекса;
- адаптивный русскоязычный интерфейс по предоставленным образцам АРМ.

Исходный классификатор проекта содержит 1 281 происшествие, 24 группы и 53 службы. Сам XLSX и исходные документы заказчика в публичный репозиторий не включаются.

## Технологии

- Frontend: React 19, TypeScript, Vite.
- Backend: FastAPI, SQLAlchemy, Alembic.
- База данных: PostgreSQL 16.
- Запуск: Docker Compose.
- Отчёты: ReportLab, CSV.
- Проверка: pytest и отдельный браузерный сценарий Playwright.

## Быстрый запуск

Нужен Docker Desktop или Docker Engine с Compose.

Windows PowerShell:

```powershell
Copy-Item .env.example .env
docker compose up -d --build
```

Linux/macOS:

```bash
cp .env.example .env
docker compose up -d --build
```

После запуска:

- интерфейс: http://localhost:5173;
- API: http://localhost:8000;
- Swagger: http://localhost:8000/docs;
- проверка состояния: http://localhost:8000/health.

Демонстрационные учётные записи:

| Роль | Логин | Пароль |
|---|---|---|
| Администратор | `admin@example.local` | `Admin123!` |
| Преподаватель | `teacher@example.local` | `Teacher123!` |
| Обучающийся | `student@example.local` | `Student123!` |

Эти пароли предназначены только для локального показа. Перед использованием в другой среде замените `SECRET_KEY`, пароли и параметры базы данных.

## Основной сценарий

1. Администратор создаёт пользователей и назначает роли.
2. Преподаватель формирует учебную группу и назначает обучающемуся профиль ДДС.
3. Преподаватель открывает пункт ЕКП, проверяет условия маршрутизации и создаёт карточку.
4. Преподаватель утверждает эталон, публикует сценарий, выбирает группу и запускает занятие.
5. Обучающийся получает карточку, меняет статусы, заполняет сведения и завершает практику.
6. Система рассчитывает баллы, сохраняет историю и формирует отчёт.
7. Преподаватель просматривает результат, динамику и выгружает PDF/CSV. При необходимости он может досрочно закрыть активные карточки с оценкой уже выполненных действий.

Пошаговый показ: [docs/STAGE5_DEMO.md](docs/STAGE5_DEMO.md).

## Классификатор ЕКП

Исходный XLSX не публикуется. Для собственной версии войдите преподавателем или администратором, откройте «ЕКП и подготовка карточек», загрузите файл, проверьте замечания и сохраните версию в справочник.

Парсер сохраняет значения всех столбцов и формулы, отделяет происшествия от групп и не додумывает неизвестные сокращения. Неоднозначные условия требуют решения и пояснения преподавателя.

## Проверка

```powershell
docker compose exec -T -e TEST_API_URL=http://localhost:8000/api backend pytest -q
```

Тесты, которым нужен полный исходный классификатор, запускаются с дополнительным `EKP_SOURCE_PATH`. Последний полный прогон проекта и исходного классификатора: 71 серверный тест, production-сборка frontend и сквозной браузерный сценарий.

## Границы прототипа

Пока не реализованы промышленный мониторинг и оповещения, TLS внутри локального контура, автоматическое ежедневное резервное копирование, отказоустойчивый кластер, реальные внешние интеграции, карта, загрузка учебных материалов и полноценный AI-анализ текста. Локальный AI-провайдер является учебной заглушкой и не влияет на детерминированный балл.

Не публикуйте `.env`, резервные копии базы, исходные материалы заказчика и реальные персональные данные. Репозиторий предназначен для проверки кода и запуска локального прототипа.
