# Архитектура

Система состоит из React/TypeScript frontend, FastAPI backend, PostgreSQL, AI Gateway, MockCallProvider и MockRTUAdapter. Все учебные операции идут внутри локального контура. REST используется для команд и CRUD, WebSocket — для событий занятия.

## RBAC

ADMIN — администрирование пользователей и конфигурации.
TEACHER — сценарии, учебные сессии, запуск/завершение, отчёты, импорт классификатора.
STUDENT — только участие в запущенной учебной сессии, ввод действий и просмотр собственного результата.

## Карточка

UI отражает референсную модель: поле «Что случилось», связанный набор тегов, выбор служб, статусы «ПРИНЯТО/НЕ ПРИНЯТО», дополнительные статусы «НАЧАЛО РЕАГИРОВАНИЯ / ОТКАЗ ОТ ВЫПОЛНЕНИЯ РАБОТ / РАБОТЫ ЗАВЕРШЕНЫ» и комментарии. В референсах указано, что правильность заполнения исходной карты заявителем диспетчер ДДС не контролирует; тренажёр поэтому оценивает именно действия обучающегося в роли ДДС.

## Оценивание

`score_actions()` сравнивает фактические действия с ExpectedAction. Временное превышение фиксируется отдельно. AI анализирует текст после выполнения карточки и возвращает feedback; AI не изменяет deterministic score.

## RTU

Интерфейс `RtuAdapter` не содержит выдуманных команд реального оборудования. Для demo используется `MockRTUAdapter`. Реальный драйвер должен быть добавлен только после получения подтверждённого протокола и спецификации от заказчика.
