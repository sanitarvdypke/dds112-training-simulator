## Остаточные ограничения и замечания

1. Ручной прогон M01–M15 открыт. Нет основания заявлять, что интерфейс прошёл полную приёмку.
2. AI, телефония и RTU — локальные имитаторы по архитектуре проекта. Реальные внешние интеграции не подключались и не проверялись.
3. WebSocket подтверждает сообщения (ACK); широковещательный мониторинг действий в реальном времени не реализован. Его нет в демонстрации.
4. Импорт XLSX сохраняет строки в staging/committed-хранилище, но не формирует из них варианты справочников карточки. В UI импорта нет. В демонстрации этот модуль не используется.
5. Панель администратора предоставляет административный доступ к учебным данным; отдельные формы управления пользователями/группами не реализованы.
6. Комментарий восстанавливается после явного «Сохранить комментарий» или завершения; несохранённый ввод при перезагрузке может быть утрачен.
7. Для seed-сценариев оставлено исходное требование точной фразы комментария. Для новых сценариев засчитывается непустой комментарий; mock AI отдельно даёт замечания.
8. Оценка относится к итоговой карточке, а не порядку всех промежуточных действий. Превышение времени — отдельная ошибка, без автоматического снятия баллов; это сохранённое правило исходного проекта.
9. В тестах есть 3 предупреждения о datetime.utcnow (не падения). Нагрузочные, многопользовательские гонки, длительная эксплуатация и аудит безопасности целиком не проводились.
10. В базе остались QA-данные и результаты демонстраций. Существующие данные не удалялись. Отдельная БД dds112_qa_clean оставлена для подтверждения чистого развёртывания.
