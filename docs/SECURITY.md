# Безопасность и изоляция

1. JWT используется для API-аутентификации.
2. RBAC проверяется на backend; скрытие кнопок frontend не является механизмом безопасности.
3. Все действия студентов журналируются через AuditLog.
4. Внешний AI отключён по умолчанию и заменён MockAIProvider.
5. Реальные экстренные вызовы не принимаются.
6. RTU интеграция отделена адаптером; неподтверждённые команды не реализуются.
7. PostgreSQL находится в отдельной сети Docker.
8. Для production требуется TLS reverse proxy, секреты вне `.env`, backup не реже суточного, ротация журналов и политика хранения не менее срока, заданного заказчиком.
