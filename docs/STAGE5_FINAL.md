# Этап 5 — интерфейс по образцам и проверка демонстрации

Дата: 29.09.2026. Локальная сборка запущена: http://localhost:5173.

## Что сделано

Интерфейс переработан по предоставленным документам «СКРИНШОТ ДДСГСИ» и «СКРИНШОТ КАРТОЧКИ 112ГСИ». Документы использованы как требования и визуальные образцы. Уточнение пользователя имеет приоритет: ученик получает готовую карточку 112; имитации голоса, звонка и разговора с пострадавшим нет.

| Образец | Реализовано | Подтверждение |
|---|---|---|
| ДДС, изображение 1 | Синий экран входа, силуэт города, знак 112, форма справа | [Вход](stage5-screenshots/login.png) |
| ДДС, изображения 2–5 | Серый реестр, компактные тёмные строки, поиск, номер/дата/время/тип/адрес/статус, раскрытие строки | [Реестр](stage5-screenshots/inbox.png) |
| ДДС, изображения 6–20 | Слева адрес и описание, справа тип и признаки, нижняя панель служб, своя служба выделена синим | [Карточка](stage5-screenshots/card.png) |
| ДДС, история и редактирование | Синяя панель истории над службами, отдельное окно статуса и комментария | [История](stage5-screenshots/history.png), [статус](stage5-screenshots/status.png) |
| Карточка 112, изображение 4 | Таймер справа сверху, прямоугольные панели и компактные поля | [Карточка](stage5-screenshots/card.png) |
| Требование адаптивности | Одна колонка на узком экране, прокрутка широких таблиц внутри блока | [390 px](stage5-screenshots/mobile-card.png) |

Панель преподавателя разделена на вкладки: занятия, обучающиеся и службы, ЕКП, сценарии и эталоны, отчёты. Для преподавателя отдельного визуального образца в приложенных документах нет; применены общие цвета и оформление ДДС. Службы подписаны понятными названиями, например «Полиция (МВД)». Технические записи скрыты переключателем, а не удалены.

Это адаптация структуры и оформления образцов, а не полная копия действующей системы 112. Карта, реальные координаты и состояния сторонних служб не выдумываются. Телефонные панели исключены по прямому указанию пользователя.

## Проверка

Полный браузерный сценарий выполнен **автоматически в Chromium**, через реальные кнопки и поля интерфейса, с реальными HTTP-запросами к backend/PostgreSQL. Ответы API не подменялись. Снимки входа, реестра, карточки, истории, окна статуса и мобильной карточки визуально просмотрены. Это не выдаётся за ручную приёмку человеком.

Проверены: назначение профиля ДДС, поиск пункта ЕКП, расчёт получателей и создание карточки, утверждение эталона и публикация, создание/запуск занятия, вход ученика, поиск/получение, три обязательных статуса, сведения ДДС, комментарий, восстановление после перезагрузки, защита черновика при выходе, завершение **9/9**, архив, подробный отчёт, скачивание CSV/PDF, завершение занятия, вход администратора. Ошибок JavaScript `pageerror`: **0**.

На этапе 5 серверная регрессия составляла **69 passed**. После добавления функций администратора и досрочного завершения занятия актуальный результат — **71 passed**. Production-сборка TypeScript/Vite успешна. Проверка не изменяла активную карточку демонстрационного ученика: для действий созданы отдельные QA-учётные записи.

## Повторный запуск

Браузерные зависимости установлены только в текущем тестовом контейнере backend; они не добавлены в production-зависимости. После пересборки backend их нужно установить повторно. Скрипт использует уже импортированный исходный ЕКП с ID `e0e407e4-524e-4250-bd4c-8f6392f682c5`; для другой БД этот ID нужно заменить. На время запуска внутри контейнера открывается локальный порт 5173 для доступа Chromium к frontend. Пользовательские данные не удаляются; новые тестовые записи имеют префикс QA.

```powershell
docker compose exec -T backend pip install playwright==1.63.0
docker compose exec -T backend python -m playwright install --with-deps chromium
docker compose cp scripts/stage5_browser_check.py backend:/tmp/stage5_browser_check.py
docker compose exec -T -e TEST_API_URL=http://localhost:8000/api backend python /tmp/stage5_browser_check.py
docker compose cp backend:/tmp/stage5/. tmp/stage5/
docker compose cp tmp/source-review/classifier.xlsx backend:/tmp/classifier.xlsx
docker compose exec -T -e EKP_SOURCE_PATH=/tmp/classifier.xlsx -e TEST_API_URL=http://localhost:8000/api backend pytest -q
```

Полная приёмка всего ТЗ пока не заявляется: открытые пункты перечислены в [состоянии относительно ТЗ](TZ_STATUS.md), включая карту, промышленные средства мониторинга и полноценный AI-анализ.
