## Команды повторной проверки

Из корня проекта:

```powershell
docker compose up -d --build
docker compose exec -T -e TEST_API_URL=http://localhost:8000/api backend pytest -q
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/demo.ps1
```

Bypass действует только для данного процесса PowerShell, политика системы не меняется.
Без TEST_API_URL интеграционные тесты пропускаются; это не полноценный прогон.
Тесты создают данные с префиксом QA и не удаляют существующие данные.
