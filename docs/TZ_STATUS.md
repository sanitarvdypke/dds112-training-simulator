# Состояние относительно ТЗ

Дата актуализации: 29.09.2026. Документ описывает фактическое состояние прототипа и не заявляет промышленную готовность.

## Реализовано

| Требование | Фактическая реализация |
|---|---|
| Три роли и RBAC | Администратор, преподаватель, обучающийся; проверки выполняются на backend |
| Управление пользователями | Создание, назначение роли, блокировка и разблокировка; самоблокировка администратора запрещена |
| Управление учебным процессом | Сценарии, эталоны, занятия, запуск, обычное и досрочное завершение |
| Учебные группы | Создание и изменение групп, назначение обучающихся, выбор группы для занятия и серверное ограничение доступа |
| Профильные события | Карточки выдаются по назначенной службе ДДС и группе |
| Карточка и действия | Получение, таймер, статусы, комментарии, сведения ДДС, журнал и архив |
| Оценивание | Порядок, нормативы, обязательные комментарии и поля; настройка утверждается преподавателем |
| Отчётность | Подробный результат, журнал, отклонения, CSV и PDF |
| Динамика обучения | Сводка по попыткам, среднему и лучшему результату, времени и последним оценкам каждого обучающегося |
| Классификатор | Версионный импорт XLSX, 90 столбцов исходника, поиск, правила и маршрутизация |
| Адаптивный интерфейс | Десктопная и мобильная компоновка; русский язык |
| Аудит | Значимые команды и действия обучающегося сохраняются в PostgreSQL |
| Состояние комплекса | Администратор видит доступность БД, пользователей, занятия, аудит, CPU, нагрузку, память и диск |

## Реализовано частично

| Требование | Ограничение прототипа |
|---|---|
| ИИ | Локальная предсказуемая заглушка; полноценной ML-модели и обучения нет |
| Мониторинг | Есть прикладной экран и метрики ресурсов контейнера; нет внешних оповещений и наблюдения за несколькими узлами |
| Резервное копирование | Есть ручной скрипт `infra/backup.sh`; нет расписания, интерфейса и проверенной процедуры восстановления |
| Уровни сложности | Поле сложности хранится в сценарии; отдельного планировщика заданий по уровням нет |
| Реальное время | WebSocket защищён токеном, но пользовательский мониторинг занятия через него не реализован |

## Не реализовано

- загрузка методических материалов и справочная база;
- полноценные AI-рекомендации и семантический анализ;
- TLS и многоуровневая аутентификация;
- автоматическое хранение журналов безопасности не менее шести месяцев;
- горизонтальный кластер и автоматическое восстановление после отказа узла;
- подтверждённая нагрузка до 100 пользователей, 20 одновременных сессий и 100 операций записи в секунду;
- реальные SIP/VoIP, RTU и другие внешние интеграции;
- карта и реальные координаты происшествия;
- сертификаты по результатам обучения.

Имитация голосового звонка исключена из согласованного учебного потока: обучающийся ДДС получает уже сформированную карточку системы 112. Это пользовательское уточнение имеет приоритет для текущей демонстрации.
